## Overview

QuickRide is a demonstration ride-sharing platform showcasing modern web development practices. This is a **demo project** with sample data and is intended for educational and portfolio purposes.

## Features

- 🚗 Ride booking interface (demo data)
- 📍 Location selection
- 💰 Sample pricing display
- ⭐ Mock user ratings
- 📱 Responsive design
- 🔐 Basic authentication system

## Installation

### Prerequisites

- Node.js (v14 or higher)
- Python (v3.8 or higher)
- npm or yarn
- pip

### Backend Setup

```bash
# Clone the repository
git clone https://github.com/harshitabisht05/quickride.git
cd quickride

# Create a virtual environment
python -m venv venv

# Activate the virtual environment
# On Windows
venv\Scripts\activate
# On macOS/Linux
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run the backend server
python app.py
```

### Frontend Setup

```bash
# Install frontend dependencies
npm install

# Start the development server
npm start
```

## Usage

1. Start the backend server (see Backend Setup above)
2. Start the frontend development server (see Frontend Setup above)
3. Open your browser and navigate to `http://localhost:3000`
4. Explore the demo interface with sample data

**Note**: This is a demo project. All data is sample/mock data and is reset when the application restarts.
