# QuickRide Frontend

React + Vite frontend for QuickRide, a vehicle rental booking demo. The app connects to the FastAPI backend, shows available vehicles, supports login/register flows, and lets authenticated users book vehicles.

## Features

- Home page with featured available vehicles
- Fleet page with searchable vehicle cards
- Vehicle cards with image, description, rating, seats, fuel type, transmission, pickup location, price, and availability
- Login and registration pages
- Protected booking and bookings pages
- Axios API client with JWT bearer token support
- Responsive styling in `src/App.css`

## Tech Stack

- React 19
- Vite 8
- React Router
- Axios
- ESLint

## Setup

Install dependencies:

```powershell
npm install
```

Create or update `frontend/.env`:

```env
VITE_API_URL=http://127.0.0.1:8000
```

Start the backend first, then run the frontend:

```powershell
npm run dev
```

Default local URL:

```text
http://127.0.0.1:5173/
```

## Backend Data Used

The vehicle UI expects these fields from `GET /vehicles/`:

```json
{
  "id": 1,
  "name": "Sedan",
  "type": "Car",
  "price_per_hour": 10.0,
  "image_url": "https://example.com/sedan.jpg",
  "description": "Comfortable city sedan with smooth handling and roomy luggage space.",
  "fuel_type": "Petrol",
  "transmission": "Automatic",
  "seats": 5,
  "rating": 4.7,
  "pickup_location": "Downtown Hub",
  "available": true
}
```

If `image_url` is missing or fails to load, the card falls back to a CSS vehicle illustration.

## Notes

- `VITE_API_URL` is required. The app throws an error if it is missing.
- Auth tokens are stored in `localStorage` under `token`.
- `dist/` is generated by `npm run build` and should not be edited manually.
